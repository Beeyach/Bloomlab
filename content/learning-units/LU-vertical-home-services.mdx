# Home Services Follow-Up

## Demonstration Build — not a client outcome

The fictional contractor handles ordinary estimate inquiries, not emergency dispatch. Its manifest has a short service inquiry form, service-area and job-type fields, a pipeline from Review to Estimate Sent to Accepted, an owner notification and a bounded follow-up workflow. A quote is not produced from a vague message; staff inspect the request and own the estimate.

Use an explicit service-area decision before offering a visit. In-area requests enter review; out-of-area requests receive the agreed boundary response without repeated estimate chasing. An urgent safety issue is routed to appropriate human guidance under the business's approved policy; this demonstration does not provide emergency instructions or a guaranteed response time.

A staff update to Estimate Sent starts the agreed reminder sequence. Acceptance, refusal, a reply or DND stops inappropriate follow-up. Re-entry must identify the job context so a repeat customer with a new request is not confused with a duplicate submission. Document that this starter uses a single active request per contact; multiple concurrent jobs justify a more careful object or opportunity model.

Location and contact details are configuration, not universal source-client text. Measure estimate response and acceptance against the estimate cohort, with unknown outcomes kept visible. Rehearse an out-of-area request, duplicate inquiry, accepted estimate and missing phone. A technically successful message to the wrong service area is a deployment failure.

## Reuse with evidence

This is an explicit Bloomwired training blueprint. Repair its supplied manifest and trace the failure case below; the shared runner saves the answers and deterministic evidence. It does not import a HighLevel snapshot or execute outbound work. A local pass verifies only these supplied contracts. A real deployment still needs permission, destination-specific QA and honest proof. Never present this fictional system as a paid engagement, live result or customer testimonial.
